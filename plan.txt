2. Functional Requirements
Feature	Description
Scripted Branching Logic	Six rounds, each with two options. Wrong → restart; right → advance.
Avatar Video Playback	Pre-generated Synthesia clips for: opening, each tip, debrief.
“Ask Tip” Modal	On click, pause text UI, play tip video or audio.
Texting Interface	Styled chat bubbles, simulated input (no free text entry).
Audio Guidance (ElevenLabs)	Optional: dynamic “free-flow” voice responses from Kirk for unstructured tips or encouragement.
State Management	Track current round, correct/incorrect, and restart logic.
Session Persistence (optional)	Allow users to pick up where they left off.
Mobile responsiveness	Two-pane → stacked layout on narrow screens.

3. Non-Functional Requirements
Performance: < 2 s load, lazy-load videos

Accessibility: Keyboard navigable, alt-text, subtitles for videos

Analytics: Track number of restarts, tip requests, completion rate

Security: API keys (ElevenLabs, Synthesia) stored server-side; rate-limit tip requests
